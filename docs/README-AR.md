# Cellulaire — ثيم Shopify

النسخة مبنية على صور Home وOur Story وContact، وصور ملف البراندنج. الصفحات والأزرار والفورم والمنتجات عناصر Shopify فعلية. بعض البانرات تحتفظ بالتصميم المسطّح الموجود في الصور، مع عنوان متاح لقارئ الشاشة وزر حقيقي. باقي النصوص والكروت والفورم قابلة للتعديل. تكبير الصور محدود بدقة الملفات المرسلة.

## المعاينة

`npm run preview` ثم افتح `http://127.0.0.1:9292/`.

الأسعار والمنتجات والسلة في المعاينة بيانات اختبار محلية. لا يتم إرسال بريد أو إنشاء طلب مدفوع.

## التركيب

ارفع `Cellulaire-1.0.0.zip` في Shopify كنسخة غير منشورة. أنشئ صفحات `our-story` و`contact` و`science` و`faq` واربط كل واحدة بالتمبلت المطابق، وأنشئ مدونة `journal`. اختر منتجاتك وكوليكشناتك من محرر الثيم، أو استخدم الـhandles الموضّحة في `store-setup.md` لتفعيل الربط التلقائي. اختَر منتج Signature Set، واضبط بيانات التواصل وروابط السوشيال.

الربط والدفع وتسليم رسائل التواصل على المتجر الفعلي يحتاجون اختبارًا داخل متجر Shopify. تفاصيل التركيب موجودة في `store-setup.md` ونتائج الاختبار في `qa-report.md`.
